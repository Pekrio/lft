====== Emulação Sem Fio 4G/LTE com srsRAN ======

O LFT possui integração nativa com o **srsRAN 4G**, um conjunto de software de código aberto para redes celulares móveis. A comunicação por radiofrequência (RF) entre as estações base e os terminais é emulada virtualmente em software através de sockets **ZeroMQ (ZMQ)** ou simulações de canal via **GNU Radio**, dispensando o uso de hardware de rádio definido por software (SDR) físico.

----

===== 1. Arquitetura da Rede 4G/LTE no LFT =====

A pilha de rede 4G é distribuída entre três contêineres principais:

<code text>
  +-------------------------------------------------------------+
  |                        LFT Framework                        |
  |                                                             |
  |   +---------------+      ZMQ Virtual RF      +----------+   |
  |   |      UE       | <======================> |   eNB    |   |
  |   | (srsue / ZMQ) |                          | (srsenb) |   |
  |   +---------------+                          +----------+   |
  |                                                    |        |
  |                                              S1-MME / S1-U  |
  |                                                    |        |
  |                                              +----------+   |
  |                                              |   EPC    |   |
  |                                              | (srsepc) |   |
  |                                              +----------+   |
  |                                                    |        |
  |                                                SGi (NAT)    |
  |                                                    v        |
  |                                               [ Internet ]  |
  +-------------------------------------------------------------+
</code>

  * **EPC (Evolved Packet Core)**: Núcleo da rede contendo os componentes MME (Mobility Management Entity), HSS (Home Subscriber Server) e SGW/PGW (Serving/Packet Data Network Gateway).
  * **eNB (eNodeB)**: Estação rádio-base LTE que gerencia os recursos de rádio e faz a ponte entre o UE e o EPC.
  * **UE (User Equipment)**: O terminal de usuário móvel que se registra no núcleo e estabelece conexões IP (PDN).

----

===== 2. Exemplo Completo de Rede 4G =====

<code python>
from profissa_lft.epc import EPC
from profissa_lft.enb import EnB
from profissa_lft.ue import UE

# 1. Definir os componentes
epc = EPC('epc')
enb = EnB('enb')
ue1 = UE('ue1')

# 2. Instanciar contêineres com a imagem srsRAN
epc.instantiate()
enb.instantiate()
ue1.instantiate()

# 3. Interconectar a interface de rede entre EPC e eNodeB (S1 Interface)
epc.connect(enb, "epc_enb", "enb_epc")
epc.setIp("192.168.180.1", 24, "epc_enb")
enb.setIp("192.168.180.2", 24, "enb_epc")

# 4. Configurar o endereço do EPC no arquivo epc.conf
epc.setEPCAddress("192.168.180.1")
epc.setSgiInterfaceAddress("172.16.0.1")

# 5. Cadastrar o chip SIM do UE no banco de usuários do EPC
# IMSI de 15 dígitos: '001010123456789'
epc.addNewUE(name="ue1", ID="001010123456789", IP="172.16.0.2")

# 6. Configurar o IMSI no UE correspondente
ue1.setIMSI("001010123456789")

# 7. Iniciar os daemons em ordem
# Inicia o núcleo EPC primeiro:
epc.start()

# Inicia a eNodeB vinculando as portas ZMQ (Tx: 2000, Rx: 2001):
enb.start(transmitterIp="*", transmitterPort=2000, receiverIp="localhost", receiverPort=2001)

# Inicia o UE conectando ao ZMQ da eNodeB (Tx: 2001, Rx: 2000):
ue_rf_args = "tx_port=tcp://enb:2001,rx_port=tcp://enb:2000,id=ue,base_srate=23.04e6"
ue1.start(deviceArgs=f"--rf.device_name=zmq --rf.device_args='{ue_rf_args}'")

print("Rede 4G/LTE emulada em execução!")
</code>

===== 3. Verificação da Conexão Celular =====

Após a sincronização do rádio e procedimento de attach:

<code bash>
# Verificar logs do EPC:
docker exec epc tail -f /srsRAN/build/epc.out

# Verificar logs do UE:
docker exec ue1 tail -f /srsRAN/build/ue.out

# O UE criará uma interface 'tun_srsue' com o IP atribuído (ex: 172.16.0.2)
docker exec ue1 ip addr show tun_srsue

# Testar conectividade de ponta a ponta:
docker exec ue1 ping -c 4 172.16.0.1
</code>
